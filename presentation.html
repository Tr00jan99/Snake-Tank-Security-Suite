SLIDE 02

Pernyataan Masalah (Problem Statement)

⚙️

Kerumitan Hardening Windows

Proses mengukuhkan sistem (seperti konfigurasi port, registry, dan polisi anonymous SAM/SID) secara manual adalah sangat rumit, leceh, dan terdedah kepada kesilapan konfigurasi.

⚖️

Kebergantungan Alatan Luar yang Berat

Scanner industri seperti Nessus/Qualys memerlukan installation server yang berat, lesen yang mahal, runtime khas (seperti Java), serta ejen latar belakang yang mengurangkan prestasi.

🛡️

Tiada Ciri Pembaikan Terus (Fix)

Hampir keseluruhan scanner keselamatan di pasaran bersifat "Read-Only" (Audit). Mereka hanya memberi tahu celah kerentanan tetapi tidak membaikinya secara programmatik.

SLIDE 03

Pengenalan Snake Tank Security Suite

  • Solusi Dwi-Tindakan Bersepadu: Menggabungkan keupayaan Pengauditan Keselamatan Sistem (Audit) dan Pengukuhan Aktif (Hardening) dalam satu platform grafik interaktif.
  • Mudah Alih Sempurna (100% Portable): Berfungsi sepenuhnya sebagai alatan sifar ejen (agentless) tanpa sebarang pemasangan. Boleh dijalankan terus daripada pemacu USB pada mesin sasaran.
  • Pembinaan Natif Windows: Kod sumber berasaskan native PowerShell 5.1 dan WPF/XAML. Ringan, laju, dan menggunakan API terbina bagi meminimumkan amaran dari perisian keselamatan (AV).
SLIDE 04

Ciri-Ciri Utama & Kehebatan Sistem

🔍

24 Audit Checks & 16 Rules

Mengimbas 24 celah kritikal termasuk RDP, firewall, kawalan akaun (UAC), autorun, dan kelayakan sistem. Diperkuat dengan 16 remedi hardening automatik.

⚡

Software & CISA KEV Auditor

Memetakan aplikasi terpasang dengan katalog ancaman global CISA KEV secara langsung. Menyokong carian rawak CVE API bertaraf dunia dengan skor CVSS berwarna.

🎯

Pembaikan Bersyarat Pintar

Sistem 'Harden All' membaca lencana UI komputer sasaran secara real-time dan hanya mengeksekusi remedi bagi status yang dikesan sebagai 'VULNERABLE' secara terpilih.

SLIDE 05

Seni Bina Teknikal & Kestabilan Sistem

Seni bina native Snake Tank direka bagi memastikan keselamatan, kualiti kod optimum, dan ketepatan operasi pada sistem operasi Windows:

User UI (WPF/XAML)
Teras grafik responsif tanpa pemproses latar belakang yang berat.
PowerShell 5.1 Engine
Pemprosesan logik, penapis ralat (Try-Catch), dan pengasingan benang (threading).
Set-RegistryDword Helper
Memaksa ketepatan jenis data REG_DWORD untuk memintas ralat OS.
External API / OS API
Carian CISA KEV JSON, CIRCL CVE, dan bacaan registry Windows.
  • Automated Test Harness: Disertakan skrip ujian unit test_harness.ps1 untuk pengesahan automatik gred profesional dengan kadar kejayaan 100%.
  • Type-Safety Enforcement: Menghalang kecacatan di mana OS menulis data registry sebagai String yang menyebabkan hardening tidak berkesan.

SLIDE 07

Aliran Kerja Demonstrasi (Demo Workflow)

Sistem operasi yang lancar bermula dari kebenaran pentadbir sistem sehinggalah proses pengauditan keselamatan selesai sepenuhnya:

1

Elevasi Admin

Perisian dijalankan sebagai Administrator bagi membenarkan akses penuh baca/tulis Registry.

2

Imbasan Audit

Menjalankan 24 checks automatik. Mengira % kepatuhan keselamatan semasa pada dashboard.

3

Analisis Software

Mengimbas aplikasi terpasang komputer dan membandingkan secara terus dengan CISA KEV global.

4

Smart Hardening

Mengklik butang 'Harden All' untuk membaiki hanya konfigurasi yang bertanda Vulnerable.

5

Verifikasi Semula

Membuat imbasan semula bagi mengesahkan semua penunjuk keselamatan kini bertukar menjadi Secure.
